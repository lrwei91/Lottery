# ticai 白纸油墨数据工作台设计简报

## 基本信息

- 项目：ticai（大乐透、排列三、2026 世界杯预测）
- 日期：2026-08-23
- 交付：纯 HTML / CSS / 原生 JavaScript 单页应用视觉与交互重构
- 设计强度：`DESIGN_VARIANCE 6 / MOTION_INTENSITY 5 / VISUAL_DENSITY 7`

## 设计判断

ticai 是高频查看、比较和操作的数据工具，不是营销站。界面以真实号码、指标、图表、历史记录和预测结果为视觉主体，采用白纸、黑墨、荧光黄与 32px 网格构成统一的编辑式工作台；不引入 Hero、玻璃拟态、低密度窄栏或持续环境动画。

## 目标与边界

- 业务目标：让开奖结果、历史数据、统计分析和预测能力处于同一套清晰、可信、可扫描的界面中。
- 用户首要任务：确认当前项目与数据日期，查看最新结果，并快速进入历史、统计或预测动作。
- 成功标准：保留既有业务行为与数据口径；320–1440px 无页面级横向溢出；主要流程可用键盘完成；减弱动效下直接显示最终状态；项目门禁通过。
- 保留：原生技术栈、Hash 路由与 DOM ID 契约、`window.App` 接口、数据结构、预测算法、Canvas 图表、云同步和设备面板。世界杯 HTML、JS 与数据保留，但当前入口和页面继续隐藏，访问 `#worldcup` 回退到大乐透。
- 移除：彩种独立主题色主导、常态卡片阴影、阻塞式载入遮罩、重复装饰动效，以及深色/跟随系统模式与颜色选择器。
- 不在本次范围：预测算法、融合权重、数据文件、API/Redis、爬虫、定时任务、提交、推送和部署。

## 视觉系统

- 画布：`#F7F7F2`
- 表面：`#FDFDF9`
- 主文本：`#171715`
- 次文本：`#53534E`
- 弱文本：`#76766F`
- 边框：`#D8D8CF`
- 品牌强调：`#FFD84D`

产品固定使用浅色模式和 `color-scheme: light`，不跟随操作系统，也不持久化颜色偏好。荧光黄是唯一品牌强调色；红蓝彩票球、冷热号、成功、警告和错误保留为业务语义色。常态表面使用实底、细边框和无阴影，仅交互悬停、浮层和模态框允许抬升。32px 网格保持低透明度，不与正文争夺注意力。

## 信息结构

1. 顶部：项目标识、项目切换与数据状态。
2. 首页：最新期号和号码为主视觉，倒计时为紧凑工具带，近期记录为账本式列表。
3. 统计：四张独立卡片合并为分隔式指标栏；图表、坐标轴和提示框读取统一的浅色语义 token。
4. 历史与预测：统一表格、筛选、焦点、状态、置信度和结果密度。
5. 设备面板与业务模态框：统一表面、边框和焦点；二维码固定黑码白底。

## 载入与动效

- 静态 HTML 中载入状态条默认隐藏，JavaScript 不可用时不遮挡内容。
- 运行时任务超过 150ms 才显示顶部非阻塞状态条；旧内容保留，并在任务期间维护 `aria-busy` 和项目切换禁用状态。
- 不设置人为最短展示时间，任务结束立即收起。
- 动效只用于首屏轻量编排、面板一次性揭示和按压反馈；没有环境漂移、指针跟随或循环动画。
- `prefers-reduced-motion: reduce` 下关闭揭示和平滑滚动，直接呈现最终状态。

## 响应式与无障碍

- 手机端全局头部不粘滞，功能导航单独粘滞。
- 多列内容在约 760px 收敛为单列；横向标签和表格仅在自身容器内滚动。
- 主要导航与动作使用原生控件；选中态、忙碌态和禁用态通过 ARIA 暴露，状态不只依赖颜色。
- 触屏不依赖 hover；键盘焦点具有清晰对比度；200% 缩放下保持核心操作可达。
