# 体彩数据工作台设计简报

## 基本信息

- 项目：ticai（大乐透、排列三、2026 世界杯预测）
- 日期：2026-07-31
- 阶段：现有产品整体改版
- 交付类型：纯 HTML / CSS / 原生 JavaScript 单页应用

## 目标与用户

- 业务目标：让开奖结果、历史数据、统计分析和预测能力处于同一套清晰、可信、可扫描的界面中。
- 目标用户及情境：在桌面或手机上快速查看最新结果、核对号码、检索历史、理解统计信号和生成预测的用户。
- 用户首要任务：确认当前彩种与数据日期，查看最新结果，并进入对应分析或预测动作。
- 主要动作：切换数据项目、切换功能区、核对号码、筛选历史、切换分析维度、生成与复制预测。
- 成功标准：保留既有业务行为与数据口径；首屏主要信息和动作清晰；各彩种共享同一设计语言；320–1440px 无横向页面溢出；主要流程可用键盘完成；减弱动效下直接显示稳定状态；项目门禁通过。
- 不在本次范围：预测算法、融合权重、数据结构、API/Redis、爬虫、定时任务和部署配置。

## 内容与状态

### 信息层级

1. 当前数据项目、数据量/日期、最新开奖结果或世界杯摘要。
2. 核对、筛选、分析和预测动作，以及支持决策的近期记录。
3. 规则说明、完整历史、模型细节、复盘记录和免责声明。

### 必须覆盖的状态

- 默认：真实数据加载后展示结果与操作。
- loading：保留明确的全页加载状态和可感知状态文本。
- 空数据：在原容器内展示简短空状态，不伪造数据。
- success：复制、绑定等操作使用对象明确的状态反馈。
- warning / error：独立语义颜色、边框和文本，不只依赖色相。
- disabled：保留控件尺寸，降低强调并阻止重复操作。
- 长内容：表格和密集数据模块内部滚动，不撑破页面。

## 视觉方向

- 一句话视觉主张：一个安静、可靠、以结果为先的数据档案台。
- 采用体系：项目自定义的主题中立语义 token；未采用可选 `paper-ink` 主题。
- 排版：系统中文字体为主，数字使用等宽字体；标题、正文、说明、标签和数据分层稳定。
- 色彩：暖白画布和深墨正文为共同基底；大乐透、排列三、世界杯只替换品牌语义色；红/蓝彩票球保留既有业务识别。
- 表面：白色实底、细边框、轻阴影；移除霓虹发光、玻璃拟态和无目的渐变。
- 密度：首屏中等密度，历史和世界杯数据区更紧凑；同组间距小于组间间距。
- 明确避免：大面积主题色、持续脉冲、装饰性 Hero、低对比文字和仅靠颜色表达状态。

## 交互与动效

- 高频操作直接可见，低频设备绑定和重置保留在设备面板中。
- 按钮、筛选、分页和切换控件具有一致的 hover、focus-visible、active、disabled 状态。
- 模态框打开后进入焦点、Tab 循环、Escape 关闭，关闭后回到触发控件；打开时锁定背景滚动。
- 动效只用于短暂的区块切换和按压反馈；主要内容不等待动画。
- `prefers-reduced-motion: reduce` 下关闭揭示、平滑滚动和非必要过渡，直接呈现最终状态。
- 页面没有持续 RAF/WebGL/视频循环；Canvas 仅在渲染或尺寸变化时重绘。

## 响应式与无障碍

- 布局切换点来自内容约束：1120px 头部换行、1024px 首页双栏、900px 世界杯摘要堆叠、720px 移动布局、480px 紧凑控件、340px 极窄处理。
- 主要导航与动作均为原生按钮；动态选中状态通过 `aria-pressed` 暴露。
- 触屏不依赖 hover；高频控件目标尺寸至少 44px。
- 表格在自身容器内滚动；320px 页面本身不产生横向溢出。
- 视口验收覆盖 320、390、768、1024、1440px，并检查 200% 缩放和减弱动效。
