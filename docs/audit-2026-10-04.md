### 4. `js/odds-utils.js:42` 存在死代码与运算符优先级 bug

- **文件**：`js/odds-utils.js:42`
- **类型**：代码问题（潜在 Bug）
- **依据**：
  ```js
  const odds = outcome.decimalOdds ?? outcome.odds ?? outcome.price === 0 ? null : (1 / (outcome.price || 0));
  ```
  存在三个问题：(a) 变量 `odds` 声明后**从未被使用**，后续逻辑用 `decimalOdds` 重新判定；(b) `??` 与 `?:` 混用未加括号，`a ?? b ?? c === 0 ? x : y` 实际解析为 `(a ?? b ?? (c===0)) ? null : (1/price)`，与注释意图"如果是 price 转成 odds"完全不符；(c) 当 `price === 0` 时会走 `1/(0||0)` = `Infinity`。当前因该变量未被使用而未爆发，但属于明确的错误代码。
- **修改建议**：直接删除该行死代码。若要保留意图，应改写为与下方 45-47 行一致的显式分支。
