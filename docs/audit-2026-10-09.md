## 3. 组合结构：唯一可优化的真实杠杆

- 50 万期蒙特卡洛（配对抽样，同一随机源跨设计对比）：
  - 42 期历史组合的期级≥1 期望为 **28.9%**（随机独立五注参照 29.19%）；
  - 完全分散设计（前区 25 个互异号、后区 10 个互异号）为 **32.3–32.5%**；
  - 直接对排列做局部搜索的最优 ≈ 32.4–32.5%，即“完全分散”已接近五注规模下的上限。
- 结论：单注概率不可优化；跨注联合结构（分散度）是唯一真实提升点。

## 4. 改动

- `js/predictor.js`（`generateMultiplePredictions`，仅大乐透）新增跨注分散层：
  - 已用号码在选号评分中降权（×0.05），并按“复用 0/1/2/不限 个号码”四级逐级放宽，
    任何情况下不新增生成失败路径；`options.spreadEnforcement='off'` 可关闭（对照/调试）。
  - PL3 路径与改动前逐字节一致（30 个种子验证），RNG 调用序列不变。
- `scripts/check-dlt-predictor.cjs`：新增五注并集回归断言（前区 ≥22、后区 ≥8，期望 25/10），
  并在输出 JSON 中附带 `frontUnion` / `backUnion`。

## 5. 验证证据

- 150 个种子、当前数据：0 失败；前区并集均值 24.75（旧 18.46）、后区并集 9.85（旧 7.31）、
  两两前区重合均值 0.025（旧 0.767）。
- 模拟对比（50 万期）：期级≥1 **29.26% → 32.17%**（每批平均 +2.90pp）；
  取舍：同期多注重复中奖 P(≥2 注) 3.84% → 1.19%（分散的数学必然；验收以“期级≥1”优先）；
  “至少一注达到六等奖以上”基本持平（3.27% → 3.31%）。
- 生成耗时 14.4ms → 24.3ms/组；`npm run check` 六项全绿（含新增回归断言）。

## 6. 后续观察点

- 上线后跟踪 20–30 期的期级≥1 注频率（期望 ~32%，单期波动大，勿短期误读）。
- 号码类策略排序、置信分层、误杀预警三项在样本继续累积（每策略 ≥50 独立期）之前视为噪声，
  不做进一步调参；任何未来改动仍按“单因素 + 模拟/留出验证”协议执行。
